# Dubai Deals AE — Dubai eCommerce Starter

A responsive, GitHub Pages-ready static storefront concept.

## Files
- `index.html` — responsive storefront
- `assets/dubai-product-hero.png` — generated lifestyle hero visual
- `promo_video.mp4` — short promotional video (if video encoder is available)
- `product-margin-notes.txt` — product shortlist and margin assumptions

## Publish with GitHub Pages
1. Create a GitHub repository, for example `dubai-deals-ae`.
2. Upload `index.html`, the `assets` folder, and `promo_video.mp4`.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site; the URL will be shown in that settings page.

## Before taking real orders
This is a front-end demo, not a complete store. It has no inventory database, checkout, payment processing, shipping integration or order admin. Add your WhatsApp number in `index.html` or connect a secure e-commerce/payment backend. Do not collect card details directly in static HTML.

## Product research note
The selection is a test shortlist, not a guarantee of current sales or profitability. Indicative cost and price figures are assumptions for planning. Confirm supplier quotations, product quality, delivery, VAT, payment fees, returns, advertising cost and applicable UAE rules before buying inventory.
